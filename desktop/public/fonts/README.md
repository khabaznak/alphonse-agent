# Bundled typefaces

Downloaded October 29, 2026 from the official Google Fonts repository:

- Manrope variable (weight 200–800): https://github.com/google/fonts/tree/main/ofl/manrope
- DM Sans variable (optical size and weight 100–1000): https://github.com/google/fonts/tree/main/ofl/dmsans

The unmodified font binaries and their respective SIL Open Font License 1.1
texts ship together. No remote font request is needed. System sans-serif fonts
provide fallbacks; diagnostic/code content uses the platform monospace stack.
