# Jev message suggestions: live assessment, 25 November 2026

This focused assessment probes the two production Noul questions and configured thresholds used for Desktop's advisory message suggestion. It is not an end-to-end Desktop or daemon exercise and never submits a conversation message. All inputs are synthetic and were sent to the configured TypeSafe service with the owner's permission and a $1 maximum. No household conversation content was used. Each receipt includes the exact synthetic state, questions, requested model, returned answers, usage, elapsed time and comparison with the case's preassigned expected outcome. No API key is retained in either receipt.

- [Initial 18 cases](evidence/jev-message-suggestion-20261125-initial.jsonl): six languages, six clear update/follow-up pairs, and six ambiguity or non-request cases.
- [Additional 18 cases](evidence/jev-message-suggestion-20261125-additional.jsonl): seven languages, seven clear pairs on different topics, and four ambiguity, mixed-intent or non-request cases. These examples were written after observing the initial results and were not used to change the production questions or thresholds; they are not a blinded sample.

Using the configured yes/no thresholds of 0.80 and 0.20, all 26 clear cases produced the preassigned route and all 10 other cases produced no suggestion. All 36 requests returned, and none had a recorded provider error. The returned model was `jev-1.14.0` for requests to `jev-latest`. TypeSafe reported 16,498 input and 1,548 output tokens across the runs; using its published price of $0.042 per million input tokens and no output charge, the estimated model usage cost is $0.000693, not an invoice or a guarantee of actual billing. Per-request observed wall times ranged from 0.192 to 0.252 seconds and totalled 7.641 seconds; these are not a product-latency benchmark.

One ambiguous draft had an update probability of 0.79, just below the 0.80 threshold. Small changes could yield a suggestion for that example; one run provides no stability or calibration estimate. A mixed-intent message yielded no suggestion. In the actual composer, no suggestion leaves the user's configured default in effect; it does not guarantee that both parts of a mixed message will be handled as intended. The samples are small, examples were translated or crafted by the evaluator, and matching the labels does not demonstrate general multilingual reliability, calibration, semantic execution, authorization or verified effects. No cancellation, provider-outage experience, concurrency under load, installed Desktop, Tauri, or real-world effect was assessed.

The earlier visual assessment used the actual React App with a disposable simulated bridge and synthetic responses. At 390 × 844 its tested conversation controls fit and the timeline scrolled, but the General settings view showed horizontal overflow; in dark mode the suggestion bubble retained a conspicuously pale background. The native Tauri shell, real daemon and Jev interaction were not visually assessed.
