# Family calendar

Use the native Google Calendar tools in the owner's private Desktop
conversation. Resolve the intended calendar, event, dates and time zone with
that owner. Ask for an exact event ID or Google Calendar event link when the
request does not identify the event sufficiently for an edit.

- Use the authorized agenda tool for event titles and times within the requested
  date range. Keep private events in the authorized conversation. Partial
  coverage leaves missing events and availability unknown.
- Use the Calendar edit proposal tool to prepare changes to an existing event.
  Show the owner where to review the exact change in Desktop. The owner approves
  the change there. A proposal alone leaves the event unchanged. If the owner
  says that the event was edited meanwhile, prepare a fresh review.
- For a requested invitation, include the exact email addresses in the proposal.
  The owner reviews the guest list and approves Google notifications in Desktop.
  The saved guest list can verify membership. Email delivery requires separate
  evidence.
- The current editing route has no automatic edits, guest removal, conference
  links, deletion, or recurrence rule changes. A recurring edit needs a specific
  occurrence or series selection. Event creation and exact free/busy are
  unavailable through the managed migration path.

[Managed setup](references/setup.md) explains the separate read and edit grants.
For scheduled use, configure a read-only Project check with the exact calendar
IDs, recipient scope, retrieval window and budgets. Report coverage gaps and
use event evidence only for the question it answers. Calendar presence cannot
verify submission, payment or completion.
