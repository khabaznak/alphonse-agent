# Managed Calendar setup

In Desktop Settings, open Integrations and connect Google Calendar for agenda
reads. Choose the exact calendar ID under the calendar's **Integrate calendar**
settings in Google Calendar. To approve event edits, connect Google Calendar
editing separately and grant it access to the exact calendar. Google consent
covers the account's calendars. Alphonse checks the selected calendar on every
use.

Alphonse reads a fresh version of the event before dispatching an approved edit.
Google MCP may accept an edit while another client is changing the same event.
Wait for the result before editing the event in Google Calendar. Review a fresh
proposal if Alphonse detects a conflict. If the result is unknown, inspect the
event in Google Calendar before requesting another update.

The old script account and its bindings can remain present for recovery.
Reconnect and grant access explicitly in Desktop to use the managed service.
