# Alphonse skill outfits

Product-owned appearance assets for issue #77. Each transparent PNG is a static
4-column, 2-row atlas. Cells in reading order are idle, planning, doing,
checking, acting, error, disconnected and an unused idle repeat.

Generated with the built-in imagegen tool using the original Alphonse idle PNG
as the character reference. The coach also used the finished doctor atlas as
a layout/style reference. Both retain the ivory spherical robot, teal fins,
metallic trim, turquoise screen eyes and matching 3D materials.

Prompt set: a consistent centered robot with transparent cell padding, seven
activity expressions, equal cells, no text, no unrelated characters. Doctor:
ivory lab jacket, teal stethoscope and neutral badge, without a red cross or
credential text. Coach: teal/coral athletic vest, coral sweatband, silver whistle
and a small dumbbell during activity. Both use cheerful idle, curious planning,
focused doing, inspecting checking, determined acting, concerned error with an
amber exclamation, and dim sleepy disconnected expressions.

These are appearance resources only. Binding, containment, fallback, selection,
preferences and validation are documented in `docs/new-ui/77-skill-appearances.md`.
